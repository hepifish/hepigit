Hepigit

A quiet Git client for the Mac. Your repositories in tabs, the history as a graph, and the everyday actions one click away.

Download for macOS
Free · macOS 15 or later · Apple silicon · Source on GitHub

Everything you reach for daily

The parts of a Git GUI people actually use, without the account, the subscription or the gigabyte of memory.

Every repo in a tab

Point it at a folder of projects, tick the ones you work on. Tabs reorder by drag; ⌘1 to ⌘9 jump between them.

A graph you can read

Branches, merges and tags in calm lanes. Drag a branch onto yours to merge or rebase.

Stage by hunk

Stage, unstage or discard a single change, a file, or everything. Amend and commit with ⌘↩.

Stashes you can see

Park your work with untracked files, look inside any stash, then pop, apply or drop it.

Your Git, your keys

It drives the git you already have. SSH config, Keychain, hooks and LFS behave as in the terminal.

Updates itself

A new release shows up in the app. One click installs it; your tabs stay where they were.

Light on purpose

Native SwiftUI, no browser engine inside. Only the visible repository is watched; the rest sleep.

First launch

Open the DMG and drag Hepigit into Applications. The app isn't notarized by Apple yet, so the first time, right-click it and choose Open. Or run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Hepigit.app

Needs git, which comes with Xcode Command Line Tools (xcode-select --install).
